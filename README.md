# Carisia AI Content Studio

Mobile-friendly AI content generation web app.

## Features
- Prayer, affirmation, special-message and social-caption generation
- AI provider integration through environment variables
- Paystack payment initialization
- Ready for deployment on Render

## Important
Do not put API keys inside GitHub files. Add them as environment variables in Render.

Required variables:
- `AI_API_KEY`
- `AI_API_URL`
- `AI_MODEL`
- `PAYSTACK_SECRET_KEY`
- `PAYSTACK_CALLBACK_URL`
- `APP_BASE_URL`
